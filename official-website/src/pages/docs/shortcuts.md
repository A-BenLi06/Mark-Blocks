## 编辑快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl` + `Z` | 撤销（Undo） |
| `Ctrl` + `Y` | 重做（Redo） |
| `Ctrl` + `F` | 查找 |
| `Ctrl` + `S` | 手动保存（自动保存关闭时常用） |

## 导航与视图

| 操作 | 功能 |
| --- | --- |
| 点击主页磁贴 | 打开最近文件 |
| 点击文件标签页 | 切换文件 |
| 开启沉浸模式（Phone） | 隐藏文件标签页 |
| 开启 Split View（Windows） | 编写 / 预览双分屏 |

## 滚动行为

Split View 下的同步滚动遵循「局部优先」：

- 滚动 **编写区**（RichEditBox）-> 预览区同步跟随。
- 滚动 **预览区**（WebView）-> 编写区不被带动。

这样在编写时便于对照，在浏览预览时不打扰光标位置。

## 触控操作

作为 Metro 应用，Mark::Blocks 全面支持触控：

- 磁贴、标签页、按钮均按触控命中区设计。
- Windows Phone 端依赖系统返回键在标签页与主页间导航。
- 支持横向滑动的标签页条带。

## 鼠标与键盘

桌面端同时支持鼠标精确操作与键盘快捷键。Split View 分隔与同步滚动在键鼠下同样工作。
