## 主页与磁贴

启动应用即进入主页。最近打开的文件以 **磁贴** 形式平铺展示，符合 Metro 开始屏幕的交互直觉：

- 点击磁贴打开文件。
- 磁贴颜色随 Accent 颜色变化。
- 主页背景可自定义，详见 [自定义设置](/docs/customization/)。

## 文件标签页

打开多个文件后，顶部出现 Metro 风格的 **文件标签页**：

- 点击标签切换文件。
- 标签页支持平滑跳转动画。
- Windows Phone 端可进入沉浸模式隐藏标签页，腾出全部屏幕给内容。

## 编写

编辑区基于 `RichEditBox`：

- 直接键入 Markdown 源码。
- `Ctrl` + `F` 唤起查找。
- `Ctrl` + `Z` / `Ctrl` + `Y` 撤销 / 重做。

## 预览

预览由 IE11 WebView 实时渲染，支持代码高亮、公式与图表。预览底色可在三种风格间切换。

## Split View（Windows 独占）

在 Windows / Windows RT 端，可启用 **Split View** 双分屏：左侧编写、右侧预览，同屏对照。

### 同步滚动规则

Split View 的同步滚动遵循「谁动谁说了算」的局部原则：

- **滚动 RichEditBox**（编写区）-> 预览区同步跟随。
- **滚动 WebView 区域**（预览区）-> 编写区**不**被带动。

这样设计便于在编写时对照查看，又在浏览预览时不打扰光标位置。

> **提示**：Windows Phone 屏幕较小，不提供 Split View。手机端为「纯净编写」与「纯净预览」两种独立模式，按需切换。

## 沉浸模式（Windows Phone 独占）

在手机端开启沉浸模式后，文件标签页被隐藏，最大化编辑 / 预览空间，适合长文写作。

## 导出 HTML

在文件菜单中选择「导出为 HTML」，应用会将当前文档连同样式打包为独立 HTML 文件，可离线分发或在浏览器中直接打开。

## 自动保存

可在设置中开关自动保存，并选择保存频率。开启后无需手动 `Ctrl` + `S`，避免意外丢失。
